# Loan Performance & Credit Risk Analysis
## Project Overview

This project focuses on analysing loan application data to understand lending patterns, approval trends, interest rates, and potential credit risk indicators.

Using a dataset containing 45,000 loan applications, I carried out data cleaning and preparation in Microsoft Excel, performed data exploration and advanced analytics using SQL, and developed an interactive dashboard using Microsoft Power BI.

The analysis explored key metrics, including total loan applications, overall loan approval rate, average interest rate, total loan value, and average credit score. It also examined loan approval patterns across different loan purposes and credit score categories, alongside patterns in applicants' income levels and home ownership.

The project demonstrates how Excel, SQL, and Power BI can be used to transform raw data into meaningful insights, identify patterns, and support data-driven decision-making.
## Business Problem

Loan providers need to assess applications carefully to balance lending opportunities with potential financial risk. Understanding applicants' credit profiles, income levels, loan purposes, and repayment-related indicators can help provide a clearer picture of lending patterns and loan approval outcomes.

However, without properly analysing loan application data, it may be difficult to identify patterns in approvals, understand how interest rates vary across applicants, or recognise characteristics associated with different lending outcomes.

This project uses data analytics to examine loan application patterns, approval rates, interest rates, and credit-related indicators to generate insights that can support better-informed lending decisions.

## Project Objectives

The objectives of this project are to:

- Analyse the overall volume and value of loan applications.
- Evaluate loan approval and rejection rates.
- Examine approval patterns across different loan purposes.
- Analyse the relationship between credit scores and interest rates.
- Explore loan application patterns across income bands and home ownership categories.
- Identify trends and patterns that could provide insights into loan performance and credit risk.

## Tools & Technologies

- **Microsoft Excel:** Used for data cleaning, preparation, handling inconsistencies, and creating analytical categories.
- **SQL:** Used for data exploration, querying, aggregation, and advanced analytics to examine loan application patterns and key performance metrics.
- **Microsoft Power BI:** Used for data visualization and developing an interactive dashboard to present insights from the analysis.

## Dataset Description

The dataset contains 45,000 loan application records with information about applicants' demographics, financial backgrounds, loan details, credit scores, and loan approval outcomes.

The dataset includes variables such as:

- Applicant age and gender
- Education level
- Annual income
- Employment experience
- Home ownership status
- Loan amount
- Loan purpose
- Interest rate
- Loan-to-income ratio
- Credit score
- Previous loan default history
- Loan approval status

These variables were used to explore loan application patterns, approval outcomes, interest rates, and potential credit risk indicators.

## Data Cleaning and Preparation

Data cleaning and preparation were carried out using Microsoft Excel to improve data quality, consistency, and suitability for analysis.

The following steps were performed:

- Checked for duplicate records.
- Checked for missing values.
- Reviewed age values for inconsistencies.
- Validated employment years against applicants' ages.
- Standardised categorical values and text entries.
- Reviewed and corrected data types.
- Recoded loan approval status for easier analysis.
- Created age groups, income bands, and credit score bands to support segmentation and comparative analysis.
- Conducted outlier checks on key financial variables, including income and loan amounts.

These steps helped prepare the dataset for further analysis using SQL and visualisation in Power BI.

## SQL Analysis

SQL was used to perform data exploration, analytical queries, and calculations to gain insights into loan applications and lending patterns.

The analysis focused on:

- Calculating the total number of loan applications.
- Analysing approved and rejected applications.
- Calculating overall loan approval and rejection rates.
- Examining average interest rates.
- Analysing loan applications across different loan purposes.
- Exploring credit scores and their relationship with loan approval outcomes.
- Analysing loan amounts across different income categories.
- Examining loan application patterns across home ownership categories.

SQL queries were used to aggregate, segment, and analyse the data to identify patterns and support further visualisation in Power BI.

## Power BI Dashboard Development

Microsoft Power BI was used to develop an interactive dashboard that presents key metrics and visual insights from the loan application dataset.

The dashboard includes five key performance indicators (KPIs):

- Total Loan Applications
- Loan Approval Rate
- Total Loan Value
- Average Interest Rate
- Average Credit Score

It also features visualisations examining:

- Loan approval rates by loan purpose.
- Loan approval rates by credit score band.
- The relationship between interest rates and credit scores.
- Loan applications by home ownership category.
- Loan amounts across income bands.

Interactive slicers were incorporated to allow users to filter the dashboard by gender, education, loan purpose, and home ownership.

The dashboard provides an interactive way to explore loan performance and identify patterns across different applicant categories.

## Key Findings

The analysis of 45,000 loan applications revealed several important insights about loan performance, approval patterns, and credit risk.

- **Loan Approval Rate:** The overall loan approval rate was 22.22%, indicating that a relatively small proportion of submitted applications received approval.

- **Loan Approval by Intent:** Debt Consolidation recorded the highest approval rate at 30.27%, followed by Medical at 27.82% and Home Improvement at 26.30%. Venture recorded the lowest approval rate at 14.43%.

- **Credit Score Analysis:** Approval rates across credit score bands were relatively close. Fair recorded 22.48%, Very Good 22.34%, Poor 22.30%, and Good 21.55%.

- **Home Ownership:** Renters accounted for the largest share of applications, representing approximately 52.1%, followed by mortgage applicants at 41.09%.

- **Loan Amount by Income Band:** The Middle-income category recorded the highest loan amount at approximately 0.21 billion, followed by Upper-Middle at 0.09 billion and Lower-Middle at 0.08 billion.

- **Average Interest Rate:** The overall average interest rate was 11.01%.

- **Average Credit Score:** The average credit score across the applications was 632.61.

- **Credit Score and Interest Rate:** The scatter plot revealed the distribution of interest rates across different credit scores, without showing an obvious strong linear relationship.

## Recommendations

Based on the findings from the analysis, the following recommendations are proposed:

- **Improve Loan Approval Processes:** Financial institutions should review their approval criteria to identify factors contributing to the relatively low approval rate.

- **Strengthen Credit Risk Assessment:** Lenders should consider multiple factors, including income, credit history, existing debt obligations, and loan purpose, rather than relying on credit scores alone.

- **Review Loan Interest Rates:** Financial institutions should ensure that interest rates reflect borrowers' risk profiles while remaining competitive and affordable.

- **Develop Income-Based Loan Strategies:** Loan products should be structured to accommodate different income categories and repayment capacities.

- **Monitor Loan Performance:** Continuous monitoring of approved loans can help identify potential repayment challenges and reduce default risks.

- **Use Data-Driven Decision Making:** Financial institutions should leverage data analytics and interactive dashboards to monitor loan performance, identify trends, and support informed lending decisions.
